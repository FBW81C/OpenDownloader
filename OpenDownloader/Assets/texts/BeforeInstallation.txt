Welcome to the OpenDownloader Installer!

OpenDownloader is a simple free and open-source Video Downloader for Windows by FBW81C.

GitHub: https://github.com/FBW81C/OpenDownloader

Features:
- Downloading Videos
- FPS selection
- Quality selection
- Mode selection (Video & Audio, Video, Audio)
- Estimated file size
- ETA
- Log
- Settings
  - Default save directory
  - Show notifications (yes/no)
  - Notification duration sec (1-10)
  - Auto save log (yes/no)
  - Log save directory

Dependencies:
- .NET 8 (Core)
- ytdlp
- ffmpeg
