Welcome to the OpenDownloader Installer!

OpenDownloader is a simple free and open-source Video Downloader for Windows by FBW81C.

GitHub: https://github.com/FBW81C/OpenDownloader

Features:
- Downloading Videos
- Format selection
- Mode selection (Video & Audio, Video, Audio)
- Estimated file size
- ETA
- Log
- Settings
  - Default save directory
  - Show notifications (yes/no)
  - Notification duration sec (1-10)
  - Show error message boxes (yes/no)
  - Auto save log (yes/no)
  - Log save directory
  - After download
    - Always navigate to file
    - Naviagte to file when notification clicked
    - Open file
    - Nothing
  - After Download remove Video
    - Always
    - When successful
    - Never
  - Advanced format selection (yes/no)
  - History
  - Updater (optional, check for updates)

Dependencies:
- .NET 8 (Core)
- ytdlp
- ffmpeg
